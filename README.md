# Booklip

A personal reading app for iOS and macOS. Import books in any common format and read them with a clean, distraction-free interface.

## Supported Formats

`.epub` · `.txt` · `.pdf` · `.md`

---

## Library

| Feature | How to use |
|---|---|
| Import books | Tap **+** → pick files from Files, iCloud, Google Drive, Dropbox, or OneDrive. Multiple files at once supported. |
| Search | Pull down the library to reveal the search bar — filters by title and author. |
| Filter by status | Segmented control at the top: **All / Reading / Read** (≥99% progress). |
| Delete a book | Long-press a card → **Delete** from the context menu. |
| Reading progress | A thin bar on each card shows how far through the book you are. |

---

## Reader

Tap any book card to open it. PDF books use a PDF viewer; all others use the text reader.

### Navigation

| Platform | Go back | Go forward | Toggle bars |
|---|---|---|---|
| iOS | Tap left third of screen | Tap right third of screen | Tap middle of screen |
| iOS | Swipe right | Swipe left | — |
| macOS | ← arrow key | → arrow key | Click anywhere |

### Top Bar

| Button | Action |
|---|---|
| ← | Return to library |
| List | Open Contents / Bookmarks / Highlights panel |
| Highlighter | Toggle highlight mode — select text then pick a color to save a highlight |
| Bookmark | Save current reading position (turns orange when already bookmarked) |

### Bottom Bar

| Button | Action |
|---|---|
| Play / waveform | Open Text-to-Speech panel |
| Down-arrow circle | Toggle auto-scroll; a speed slider (tortoise → hare) appears while active |
| Aa | Open Appearance panel |
| Progress bar | Drag to scrub to any position in the book |
| Percentage | Current reading position (read-only) |

---

## Appearance

Open via the **Aa** button in the bottom bar. Settings are saved and restored per book.

- **Color themes:** Default, Sepia, Dark, Forest, Ocean, Rose
- **Fonts:** 13 options including Georgia, Helvetica Neue, Courier New, and three Korean fonts (Apple SD Gothic Neo, Apple Myungjo, GungSeo)
- **Font size:** 12–32 pt
- **Line spacing:** adjustable
- **Page turn animation:** Vertical Slide or Paper Book flip
- **EPUB embedded font:** toggle to use the font bundled inside the EPUB file

---

## Text-to-Speech

Open via the play button in the bottom bar. Playback starts from your current reading position.

- Choose any voice installed on your device
- Adjust speech **rate** and **pitch**
- Set a **sleep timer** (5, 15, 30, 45, or 60 minutes)
- The currently spoken text is highlighted live in the reader and the view scrolls to follow

---

## Contents / Bookmarks / Highlights

Open via the list icon in the top bar. Three tabs:

- **Contents** — EPUB chapter list; tap any chapter to jump to it instantly
- **Bookmarks** — saved positions with a text snippet; tap to jump, swipe to delete
- **Highlights** — all saved highlights with color indicator and snippet; tap to jump, swipe to delete

---

## Reading Statistics

Accessible from the library (stats icon).

- Total time read (hours and minutes)
- Current consecutive-day reading streak
- Counts of books in library, in progress, and finished
